Medical Device Interface

UI/UX Design | October 2025

Project Overview:

UI/UX design for a touchscreen medical device adhering to FDA usability guidelines.

The device’s original user interface was developed by engineers for experimental use in a laboratory setting. While functional, it was not designed with medical personnel or FDA usability standards in mind.

My goal was to migrate this interface into a safe, intuitive, and FDA-compliant design suitable for hospital environments.

This redesign required introducing safety protocols, refining the panel interface, and establishing a visual system that helped enforce safety procedures while mitigating potential hazards.

Throughout this process, I followed FDA usability guidelines and collaborated closely with engineers and the project manager to ensure regulatory and practical requirements were met.

Mapping User Tasks

Worked with the project manager to map each user task and identify where errors could occur. Every row from this shared spreadsheet describes a guided screen in the new interface to make sure no critical step is missed before treatment begins.
